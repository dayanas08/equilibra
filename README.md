# Equilibra

> Compartir también es equilibrar. / Sharing is about balance.

[Español](#español) · [English](#english)

## Español

Equilibra es una aplicación web progresiva (PWA) para organizar la convivencia de familias, parejas y compañeros de vivienda, inicialmente en Ecuador (USD).

### Alcance previsto
- Hogares, integrantes y permisos.
- Gastos compartidos, distribución ponderada, balances y reembolsos.
- Tareas domésticas y rotaciones básicas.
- Mascotas y distribución de sus gastos.
- Panel de control e instalación PWA.

Los acuerdos digitales, inventario y predicción de consumo se contemplan para versiones posteriores.

### Estado actual
Sprint 0, fase de preparación. Este repositorio contiene únicamente la estructura inicial y documentación de colaboración. Todavía no existe una aplicación ejecutable, autenticación, base de datos ni despliegue.

### Tecnologías propuestas
Next.js, TypeScript, Tailwind CSS, Python, FastAPI, PostgreSQL y Supabase Auth. La arquitectura y versiones se validarán en EQ-005 y el entorno se configurará en EQ-007.

## English

Equilibra is a planned progressive web application for collaborative household management, initially targeting Ecuador (USD). It will support household membership, weighted expense splitting, balances, reimbursements, chores and pet-related expenses. Digital agreements and inventory are planned for later releases.

**Current status:** Sprint 0, repository scaffolding only. No runnable application, database, authentication or deployment exists yet.

**Proposed stack:** Next.js, TypeScript, Tailwind CSS, Python, FastAPI, PostgreSQL and Supabase Auth, pending architecture approval.

See [CONTRIBUTING.md](CONTRIBUTING.md) for contribution guidelines and [docs/README.md](docs/README.md) for the documentation roadmap.
